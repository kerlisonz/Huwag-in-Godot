# Addons

Dependências opcionais de editor mantidas no repositório (ambas desativadas por padrão em `project.godot` para privilegiar o runtime 100% nativo em Godot 4 / GDScript):

- `AsepriteWizard` (`9.8.0`, licença MIT) — importação direta de arquivos `.ase` / `.aseprite` caso animações em Aseprite sejam adicionadas futuramente.
- `better-terrain` (Unlicense / Domínio Público) — *autotiling* auxiliar para expansão manual de mapas em `TileMapLayer` / `TileSet`.

Consulte [`docs/recursos-e-licencas.md`](../docs/recursos-e-licencas.md) para detalhes de licenças e histórico de limpeza.
