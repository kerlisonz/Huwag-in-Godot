# Personagens

Jogador, NPCs e criaturas como cenas independentes (`.tscn`); seus scripts ficam em `scripts/characters/`.

- `Player.tscn` — controlador base do jogador (`scripts/characters/player.gd`).
- `huwag.tscn` — instância compatível de Huwag para as cenas da floresta.
- `NpcEntity.tscn` — entidade genérica de morador/bombeiro com suporte a versão distorcida e combate hostil (`scripts/characters/npc_entity.gd`).
- `aquatic_creature.tscn` — guardiã aquática da lagoa (`scripts/characters/aquatic_creature.gd`).
