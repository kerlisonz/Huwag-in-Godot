# Interface

Cenas de diálogo, escolhas e HUD.

- `DialogueBox.tscn` — caixa de diálogo com retratos dinâmicos/CRT, escolhas com escalada hostil e efeito de máquina de escrever (`scripts/ui/dialogue_box.gd`).
- O HUD principal vive em `scenes/main/Main.tscn` e é controlado por `scripts/main/main.gd`.
- Telas de título e créditos ficam em `scenes/menu/`.
