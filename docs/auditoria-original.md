# Auditoria do projeto original

Fonte: [kerlisonz/Huwag](https://github.com/kerlisonz/Huwag), branch master, consultado em 10/11/2026. Foram lidos README, GDD, guia de desenvolvimento, switches, roadmap, relatório J-ABS, AGENTS e avisos de terceiros.

O projeto original é descrito como RPG top-down de terror psicológico, cerca de 30 minutos, ambientado nas Filipinas. Huwag Matitiis é um bombeiro de 23 anos. Os Atos 1 e 2 mostram uma realidade colorida/lúdica associada aos medicamentos; o Ato 3 revela a realidade monocromática. Os pilares incluem dilemas de resgate ambíguos e encontros com opções atacar, conversar, observar ou fugir.

O guia descreve quarto, quartel, cidade, floresta e clareira; encontro com criatura aquática, ovos e magia de água no Ato 1; incêndios, tarefas de resgate e um gatinho no Ato 2. README indica que parte dos mapas existia, J-ABS tinha uma demo funcional e arte/áudio eram placeholders MZ.

O repositório também possui instruções AGENTS, uma skill Ponytail e skills de design de jogo, áudio, nível, narrativa e arte técnica no diretório Qoder. Este pacote mantém instruções focadas em Godot e na continuidade, sem carregar regras de MZ.

**Limite:** esta nota não substitui o inventário de cada evento, mapa, asset, plugin e documento de referência. Consulte o checkout integral antes de migrar cenas específicas. O projeto Godot aqui é novo; o diretório MZ deve permanecer intacto.
