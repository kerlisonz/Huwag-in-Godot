# Logs

Artefatos de execução, captura e depuração. Não fazem parte do jogo e são ignorados pelo Git (ver `.gitignore`).

Arquivos esperados:

- `capture_log.txt` — saída das capturas de tela.
- `debug_log.txt` — passos de depuração da cena principal.
- `test_out.txt` — saída bruta de execuções de teste.
