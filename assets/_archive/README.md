# Archive

Pacotes mantidos para referência, mas **não usados em runtime**. O arquivo `.gdignore` impede que o Godot importe esta pasta.

## O que há aqui

- **Incompatíveis com a direção de arte:** `Tiny Swords (Free Pack)` (isométrico), `Pixel Art Platformer - Village Props v2.3.2` (visão lateral) e `[FREE] Mini Dungeon Tileset` (fantasia medieval escura).
- **Não referenciados no código:** `char free`, `fishing_free`, `free version`, `Interior free`, `nature free`, `opp-assets`, `PostApocalypse_AssetPack_v1.1.2`, `stringstar fields`, `town free`, `winter free`.
- **Duplicata:** `Modern_Interiors_Free_v2.2_duplicate` (cópia de `Modern_Interiors_Free_v2.2(1)`).
- **Referência anatômica:** `male_hero_free` (Ozzbit Games), base usada para construir os spritesheets de Huwag.

Para reutilizar um pacote, mova-o para `../third_party/`, remova o `.gdignore` da pasta de destino e registre a licença em `docs/recursos-e-licencas.md`.
